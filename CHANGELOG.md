# Changelog

## 0.2.0 — 2026-04-25

- SDK and protocol hardening across TypeScript, Python, Go, and Rust
- Public `@slop-ai/discovery` and local provider discovery
- Turnkey MCP Apps bridge for exposing SLOP providers in MCP Apps hosts
- Docs for installed bridge vs custom MCP App
- CLI release assets for supported platforms

SLOP is complementary to MCP: use MCP for tools, SLOP when the agent needs live application state.

## 0.1.0 — 2026-04-03

First public release of the protocol, SDKs, Chrome extension, desktop app, CLI, and docs.
